СПРАВКА ПО ФОРМИРОВАНИЮ КОДА

Текущая внутренняя структура:

PP | BBB | NNNNNNN | C

PP — двухзначный внутренний префикс.
BBB — трёхзначный внутренний код смены / бригадира.
NNNNNNN — семизначный номер товара из отдельного справочника.
C — контрольная цифра EAN-13.

Пример:
20 | 627 | 0000001 | C
→ 2062700000016

КОД СМЕНЫ

Можно использовать любой уникальный код 000–999.

Для запоминаемого кода можно использовать правило:
первые три латинские буквы имени → цифры телефонной клавиатуры T9.

MAR → 627
TAT → 828
NAT → 628

Это внутреннее правило предприятия, а не правило GS1.

НОМЕР ТОВАРА

NNNNNNN — просто идентификатор позиции из отдельного справочника.

При пакетной генерации увеличивается только номер товара:
0000001
0000002
0000003
...

Контрольная цифра каждый раз рассчитывается заново.

КОНТРОЛЬНАЯ ЦИФРА EAN-13

Первые 12 цифр обозначим D1...D12.

Сумма:

S = (D1+D3+D5+D7+D9+D11)
  + 3×(D2+D4+D6+D8+D10+D12)

Контрольная цифра:

C = (10 - (S mod 10)) mod 10

C всегда является 13-й цифрой.

ВНУТРЕННИЙ КОД И ВНЕШНИЙ GTIN

Текущая схема является внутренней схемой учёта.
Она не присваивает официальный глобально уникальный GTIN.

Если товару впоследствии присваивается внешний GTIN, внутренний номер не
надо пытаться "исправить" заменой одной цифры.

После присвоения внешнего GTIN могут измениться ВСЕ первые 12 цифр:

1. Внутренний префикс PP может полностью измениться.
2. Код смены BBB обычно вообще не входит во внешний GTIN.
3. Внутренний номер товара NNNNNNN может быть заменён внешней товарной ссылкой.
4. Контрольная, 13-я цифра C обязательно пересчитывается из новых первых 12 цифр.

То есть после присвоения внешнего кода меняется сама структура номера,
а не только контрольная цифра.

Информацию о смене, партии и производстве после этого обычно хранят отдельно:
LOT / SERIE, дата производства, внутренняя база, дополнительная маркировка.

ВАЖНО

Диапазоны и правила Restricted Circulation Numbers могут зависеть от локальных
правил GS1. Для внешней торговли нужно использовать официально присвоенный GTIN
и правила GS1, применимые к вашей организации и стране.
